# Lumina POS — Agent Development Starter Pack

This is a **planning and agent-instruction pack**, not yet a runnable application.

## Contents
- `docs/TECHNICAL_BLUEPRINT.md`: approved draft scope and proposed architecture.
- `AGENTS.md`: mandatory rules for AI coding agents.
- `docs/tickets/LUM-001-foundation.md`: first bounded coding assignment.

## Start
1. Create a new private GitHub repository named `lumina-pos` (do not initialise with conflicting generated project files).
2. Download/unzip this pack into an empty local `lumina-pos` directory.
3. Open the directory in VS Code and sign in to Codex via its official extension or client.
4. Initialise and commit these starter documents to `main`.
5. Create/switch to `feature/LUM-001-foundation` and give Codex the prompt at the end of the ticket.
6. Review changed files and testing report before merging.

## Important
The V1 blueprint is a proposed baseline. Hardware selection, BTN rounding/tax treatment, cloud hosting and receipt numbering require review before their corresponding production features. No real sales or financial data should be imported into a development environment.
